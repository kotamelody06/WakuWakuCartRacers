# わくわくカートレーサーズ（Godot 4 / Android）

企画書どおりに作った 3D カートレースゲームです。Godot 4.3 で動作確認しています（4.3 以降の 4.x で開けます）。

## タイトル画面のメニュー

| メニュー | 流れ |
|---|---|
| みんなで対戦（LAN） | 同じWi-Fiの家族と最大4人で対戦（下の説明） |
| グランプリ | カップ選択（＋難易度）→ キャラクター → カート → 4レース（毎回ポイント順位画面）→ FINISH! → CHAMPION! → 表彰台 → 報酬・アンロック |
| 1レース | キャラクター → カート → コース選択（12コース＋難易度）→ レース → リザルト |
| タイムアタック | キャラクター → カート → コース選択 → 1人で3周（スピードブースト3回つき）→ ラップタイムとベスト記録 |
| ガレージ | コイン、トロフィー（カップ×難易度）、カートのコレクション |
| オプション | BGM・効果音の音量、オートアクセル、カメラのゆれ |

## みんなで対戦（LAN対戦）

同じWi-Fiにつないだスマホ・タブレット同士で、最大4人で同時にレースできます。インターネットやサーバーは使いません。

1. 全員がタイトルの「みんなで対戦（LAN）」を開き、なまえを入れる（「パパ」「ママ」などのボタンもあります）
2. 1台が **「部屋をつくる（親機）」**。画面に **部屋番号**（例：23）が出ます
3. ほかの人は **「部屋にはいる（子機）」**。「見つかった部屋」をタップするか、部屋番号を入れて「はいる」
4. 部屋の中で、それぞれ **キャラ・カート・ハンデ** を選ぶ（全員の画面に表示されます）
5. 親機が **コース・CPUの強さ・CPUを入れるか** を決めて「スタート！」
6. ゴール後は全員に結果が出ます。親機の「もういちど（部屋へ）」で全員が部屋にもどり、続けて遊べます

* 4人より少ないときは、あいている所をCPUが走ります（オフにもできます）
* 親機がレースを計算するので、親機にはいちばん性能のいい端末（Android 14 のスマホなど）がおすすめです
* 途中でぬけた人のカートはCPUが運転を続けます。親機がぬけるとレースは終わります
* 「見つかった部屋」が出ないとき（iPad やルーターの設定によって）は部屋番号で入ってください
* つながらないときは：全員が同じWi-Fi（ゲスト用Wi-Fiでないもの）につながっているか確認してください

## ハンデ設定

カート選択画面（LANでは部屋の中）で、1人ずつ選べます。

| ハンデ | 内容 |
|---|---|
| ハンドル補助 | 手をはなしていても道なりに走ります。ハンドルを切るとその分だけ曲がり、ドリフト中も外にふくらみすぎないよう助けます |
| はやいカート | 最高速度が約7%、加速が約15%アップ |

小さい子は「ハンドル補助」＋「オートアクセル（オプション）」にすると、アイテムとドリフトだけで遊べます。

## グランプリモード

* **カップ（各4レース）**
  * グリーンカップ（初心者向け）：わくわく草原 → フルーツロード → ひなたビーチ → にじいろサーキット
  * アドベンチャーカップ（中級）：ぐつぐつ火山 → ジャングルロード → 砂漠遺跡 → 洞窟コース
  * スターダストカップ（上級）：キラキラ雪山 → 星空ハイウェイ → 雲の上コース → スターダストサーキット
* **ポイント**：1位10pt／2位8pt／3位6pt／4位5pt／5位4pt／6位3pt。4レースの合計で最終順位が決まります
* **ライバル**：カップの間は同じ5人のCPUと戦います。2レース目からはポイントの多い人ほど前からスタートします
* **順位画面**：各レースのあとに「第○レース終了」を表示。ポイントが数え上がって、順位が入れかわるアニメーションつき
* **最終結果**：FINISH! → CHAMPION!（優勝者と合計ポイント）→ 表彰台に上位3人
* **報酬**：1位 300コイン＋金トロフィー／2位 200コイン＋銀／3位 100コイン＋銅／4〜6位 30コイン
  （ふつうは1.5倍、むずかしいは2倍）
* **アンロック**：3つのカップすべてで優勝すると「ゴールデンカート」が使えるようになります
* **難易度**

| | やさしい | ふつう | むずかしい |
|---|---|---|---|
| CPUの速さ | ゆっくり | ふつう | 速い |
| CPUのアイテム | たまに使う | ふつう | どんどん使う |
| CPUのミス | 多い | 少し | なし |
| コースのギミック | 障害物が半分・遅い、落ちる場所に柵 | ふつう | 障害物が増えて速い、車が増える |

## 入っているもの（第1回からの内容）

* キャラクター4人：ライ／ミミ（うさぎ）／ガメロン（カメ）／コン（キツネ）
* カート4台：スピードスター／バランサー／ダッシュバグ／ゴールデンカート（アンロック）
* アイテム：スピードブースト／スピンボール／バリア／ロケットダッシュ／すべすべボール
* CPU：コースに沿った走行、カーブでのドリフト、アイテム使用、プレイヤー追跡、障害物よけ、コース復帰
* 演出：スタート信号・GO時のカメラ揺れ／タイヤ煙／スピード線、着地の「ドン！」、ブーストの炎、スリップ、衝突の火花
* サウンド：オリジナルBGM（タイトル・12コース・リザルト・表彰式）と効果音
* セーブ：コイン・トロフィー・アンロック・ベストタイム（1レース／タイムアタック別）・設定を自動保存

画像・3Dモデル・音はすべてこのプロジェクト内で作ったオリジナル（外部素材なし）。フォントは Noto Sans CJK JP（SIL OFL 1.1、`fonts/` にライセンス同梱）を必要な文字だけに絞って使っています。
スマホ向けに、色だけちがう図形はまとめて1つのメッシュにして描画回数をへらしています。

## PCで動かす

1. [Godot 4.3 以降](https://godotengine.org/download) をインストール
2. Godot を起動して「インポート」→ このフォルダの `project.godot` を選ぶ
3. 右上の ▶（F5）で実行。マウスクリックで画面のボタンも押せます

## Androidで動かす（APK作成）

1. Godot の「エディター → エディター設定 → エクスポート → Android」で Java SDK と Android SDK のパスを設定
2. 「エディター → エクスポートテンプレートの管理」からテンプレートをダウンロード
3. 「プロジェクト → エクスポート」→ プリセット「Android」を選び「プロジェクトのエクスポート」
   * LAN対戦に必要な権限（インターネット・Wi-Fi状態）は設定ずみです。Android 12・14 で使えます
   * USB でスマホをつなげば、右上の Android アイコンから直接インストールして遊べます
   * ストア公開時は `package/unique_name` を自分のものに変え、リリース用キーストアを設定してください

## iPad で動かす

iPad 用は Mac と Xcode で作ります。手順は `IPAD.md` を見てください（書き出し設定「iPad」は入っています）。

## フォルダ構成

```
scenes/   MainMenu, LanLobby, CupSelect, CharacterSelect, KartSelect, CourseSelect,
          Race, Result, GPStandings, Podium, Garage
scripts/
  game.gd          データ表（キャラ・カート・12コース・3カップ・難易度）とセーブ
  grand_prix.gd    GrandPrixManager：CurrentCup / CurrentRace / ポイント / ライバル / 報酬
  race.gd          RaceManager：スタート演出・周回・順位・アイテム・カメラ
  track.gd         Track：コースの形・橋・トンネル・ジャンプ台・ダッシュ板・テーマ別の飾り
  themes.gd        コースのテーマ（空・光・路面・柵の色）
  gimmicks.gd      動く障害物（カニ・丸太・トロッコ・車・いん石など）
  kart.gd          Player/CPU共通のカート挙動
  cpu_brain.gd     CPU の頭脳（難易度で速さ・アイテム・ミスが変わる）
  cup_select.gd / gp_standings.gd / podium.gd / garage.gd   グランプリとガレージの画面
  net.gd           LAN対戦の通信（部屋づくり・部屋さがし・操作と状態の送受信）
  lan_lobby.gd     LAN対戦の部屋の画面
  hud.gd / touch_controls.gd   画面表示とタップ操作
  models.gd        キャラクター・カート・アイテムの3Dモデル（図形から生成）
  sfx.gd           BGM・効果音
audio/    オリジナルBGM・効果音
tests/    開発用の自動テスト（書き出しには含まれません）
```

## コースやカップを増やすには

`scripts/game.gd` の `COURSES` に、中心線の点（x, 高さ, z）とテーマを足すと新しいコースになります。
ジャンプ台・穴・トンネル・ダッシュ板・障害物の位置は「スタートからの距離（m）」で書けます。
`CUPS` にコースの id を4つ並べると、新しいカップがグランプリに増えます。
